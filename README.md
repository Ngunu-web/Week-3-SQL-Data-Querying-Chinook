# SQL Data Querying Project – Chinook Database

## Overview
This project was completed as part of the AnalystLab Africa Data Analytics Internship Program.

The objective was to develop SQL querying skills by extracting, transforming, and analyzing data from the Chinook Database using PostgreSQL.

## Skills Demonstrated
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate Functions (SUM, AVG, COUNT)
- INNER JOINs
- Subqueries
- Window Functions
- Query Optimization

## Business Questions Answered
- Top-performing customers
- Revenue trends
- Revenue by country
- Customer purchasing behavior

## Tools Used
- PostgreSQL
- pgAdmin 4
- GitHub

## Key Learnings
This project strengthened my ability to write SQL queries, analyze relational databases, and generate actionable business insights.
